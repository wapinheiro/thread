# Changelog

Tracks major naming and structural decisions for Thred. See
[GLOSSARY.md](docs/core/GLOSSARY.md) for the full renamed-terms
reference.

## [Unreleased] — Initial Rebrand from RedThread

### Renamed
- Project renamed from **RedThread** to **Thred**.
- **Signal / Signal Score** → **Market GPA**.
- Journey stage names simplified (see Glossary for full stage-by-stage
  mapping): "The Anchor" → "Getting Started," "The Surveying" → "Gap
  Analysis," "The Oracle's Nod" → "Advisor Review," "The Treasure" →
  "Payoff & Loop," etc.
- Milestone bonus names de-gamified: "The Trifecta" → "Core Skills
  Complete," etc.
- "Risk Dashboard" / "Senior Panic" → "Early-Warning Dashboard" /
  "At-Risk Cohort."

### Retired from Core Program
- Rank ladder (GHOST, ECHO, GLITCH, ANOMALY, SIGNAL, SOURCE) — replaced
  with plain-language Readiness Bands.
- "Hz" scoring unit — replaced with plain points.
- AI personas (The Oracle, The Filter, The Architect) — functions
  retained, personas dropped; core program is now persona-agnostic by
  design.
- Cyberpunk/Matrix visual theme and "Signal vs. Noise" narrative.
- Hard Employability Gate — softened to a recommendation gate so
  component programs aren't blocked by internal scoring.

### Added
- **Theme** as an explicit layer above Philosophy — the shared
  vocabulary/tone every component program inherits.
- **Component Program** concept and the Partner Registry / Partner
  Template system, enabling other BYU CS initiatives (e.g., milestone
  sticker programs, alumni groups) to plug into the umbrella journey.
- Ariadne's thread as the project's origin metaphor — explicitly scoped
  to the *thread and the equipping gesture only*, not the full myth or
  its ending, and not extended to a Minotaur/adversarial framing.
- `docs/future/GAME_SKIN_CONCEPT.md` as an explicitly optional, later
  layer — quarantining old persona/rank ideas without discarding them.

### Kept (Mechanics Unchanged)
- Signaling Theory as the philosophical foundation.
- Leading vs. lagging indicator framing.
- Non-linear base-value scoring curve (Level 1 → 5).
- Quality Multiplier system for Level 3+ Artifacts.
- Review cooldown mechanic (narrative dropped, mechanic kept).
- 8-stage journey structure.
- Steering Committee governance model.
