# Contributing to Thred

This repository currently documents Thred's concept, philosophy, and
structure ahead of implementation.

## Proposing a Component Program

If you run or represent a BYU CS initiative you'd like to connect to
Thred, start with the [Partner Template](docs/partners/TEMPLATE.md).
Copy it to `docs/partners/<your-program-name>.md`, fill it out, and open
a pull request. It will be reviewed by the Steering Committee — see
[Governance](docs/ecosystem/GOVERNANCE.md).

## Proposing Changes to Core Concepts

Changes to core philosophy, the journey model, scoring, or the data model
should:

1. Reference the relevant existing doc in `docs/core/`.
2. Explain the reasoning, not just the change.
3. Be logged in [CHANGELOG.md](CHANGELOG.md) once merged.

## Terminology

Please check [GLOSSARY.md](docs/core/GLOSSARY.md) before introducing new
terms — a lot of naming decisions here were made deliberately (and some
were renamed once already). If you think an existing term should change,
propose it with reasoning rather than replacing it silently.
