# Future / Optional: Game Skin Concept

**Status: not part of the core Thred program. Parking lot only.**

Thred's core program is deliberately persona-agnostic and
mechanism-agnostic (see [Theme](../core/THEME.md), Section 2, and
[Glossary](../core/GLOSSARY.md)). Everything in this document is a
**possible future "dimensional representation"** — a specific,
game-flavored skin that could be built *on top of* the core program, not
a required part of it.

Nothing here should influence core journey stage names, data model
design, or scoring mechanics. If any of it eventually gets built, it
should be implemented as a presentation layer that reads from the same
underlying Thred data — not as a fork of the core logic.

## Origin

This concept comes from the earlier **RedThread** iteration of this
project, which had a full cyberpunk/hacker narrative layer: a rank
ladder (GHOST → SOURCE), a scoring unit called "Hz," and three AI
personas (The Oracle, The Filter, The Architect). That layer is retired
from the core program (see [Glossary](../core/GLOSSARY.md)) but preserved
here in case a future, explicitly optional "game mode" is worth building
— e.g., as a way to re-engage students who respond well to game-like
framing, without imposing that framing on everyone.

## Retained Ideas Worth Revisiting

- **Rank ladder** as a gamified restatement of Readiness Bands.
- **AI personas** (a guide, a quality-gatekeeper, a locked "insider
  strategist") as optional character-driven wrappers around existing
  Thred functions (guidance, Artifact review, advanced job-search
  content).
- **Narrative framing** of the labyrinth as an explorable, game-like
  space — with the explicit caveat (see Theme, Section 1) that any such
  representation should avoid casting the job market as a monster to be
  defeated, since that reintroduces an adversarial framing the core
  program has deliberately moved away from.

## Explicitly Out of Scope for Any Future Version

- A Minotaur or any adversarial-monster framing of the job market.
- Any narrative that resolves the Ariadne/Theseus myth's actual ending —
  Thred borrows the thread and the equipping gesture, not the plot (see
  [README](../../README.md)).
