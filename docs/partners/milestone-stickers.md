## Program Name

Milestone Stickers

## One-Line Description

A lightweight, physical/visible recognition program that awards stickers
for completing specific, well-defined career-prep milestones.

## Owner

*TBD*

## Goal

Give students frequent, low-friction recognition for small wins, to
build momentum early — especially useful at Levels 1–2, where Thred's
own scaffolding calls for lightweight evidence over high-effort proof.

## Integration Point 1 — Resource Registry

- **Resource type:** Milestone challenge
- **Skills it maps to:** Broad — often foundational-level skills across
  multiple Tracks (e.g., "attend your first hackathon," "set up a GitHub
  profile," "attend a resume workshop")
- **Time cost:** Low (typically under a few hours per milestone)
- **How students engage:** Complete a defined action; claim the sticker
  in person or via the program's own tracking.

## Integration Point 2 — Artifacts

- **Artifact type:** Sticker/milestone completion record
- **How it's verified:** Staff confirmation at time of award
- **Does it feed Market GPA?** Partially — contributes at Level 1
  ("Exposed") base value only, consistent with its role as lightweight,
  early-stage evidence. Does not itself satisfy Level 3+ requirements.
