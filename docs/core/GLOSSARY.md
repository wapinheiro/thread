# Thred: Glossary

This glossary is the canonical term list for Thred. It also records what
each term replaced from the original **RedThread** concept, so past docs,
conversations, or diagrams can be read correctly against current naming.

---

## Canonical Terms

| Term | Definition |
| :--- | :--- |
| **Thred** | The umbrella program connecting BYU CS career-preparation efforts into one continuous, student-facing journey. |
| **Journey** | A student's ongoing path through Thred, from onboarding through repeated cycles of gap-closing. |
| **Track** | A target career direction with a defined set of required skills and proficiency levels. |
| **Gap** | The distance between a student's current proficiency and a Track's target proficiency for a given skill. |
| **Artifact** | Verifiable evidence of completed work submitted to close a Gap (e.g., a repo, a recorded demo, a logged interaction). |
| **Market GPA** | The single, continuous, weighted metric representing a student's verified market readiness. |
| **Quality Multiplier** | A modifier (0.0x–1.5x) applied to Level 3+ Artifacts based on reviewed quality. |
| **Milestone Bonus** | Extra Market GPA awarded for completing a meaningful set of related skills. |
| **Resource Registry** | The catalog of internal resources and component-program offerings mapped to Gaps. |
| **Component Program** | Any BYU CS initiative (advising, clubs, alumni groups, milestone programs, etc.) that plugs into Thred via the [Partner Template](../partners/TEMPLATE.md). |
| **Readiness Band** | A plain-language description of a Market GPA range (e.g., "Building," "Market Ready"). |
| **Steering Committee** | The shared-governance body overseeing Track approval, scoring weight changes, and ecosystem-wide decisions. |

## Renamed / Retired Terms (from RedThread)

| RedThread Term | Status | Thred Equivalent | Notes |
| :--- | :--- | :--- | :--- |
| Signal / Signal Score / Signal Strength | Renamed | Market GPA | Same underlying concept (Signaling Theory); renamed to be plain-language and to explicitly parallel Academic GPA. |
| "Hz" (scoring unit) | Retired | Points | Was purely cosmetic to the prior theme. |
| GHOST / ECHO / GLITCH / ANOMALY / SIGNAL / SOURCE (ranks) | Retired | Readiness Bands (Getting Started / Building / Strong / Market Ready / Exceptional) | Gamified rank ladder tied to a prior cyberpunk theme; replaced with descriptive, non-competitive bands. |
| The Oracle (AI guide persona) | Retired | — (function absorbed into "Advisor Review" and general guidance functions) | Thred's core program is persona-agnostic; see [Theme](THEME.md), Section 2. A persona may exist in a future, optional game skin. |
| The Filter (AI gatekeeper persona) | Retired | Quality Multiplier / Artifact Review (function) | The verification *function* is kept; the antagonist *persona* is dropped. |
| The Architect (locked reward persona) | Retired | — (function absorbed into the Readiness recommendation gate) | See [Philosophy](PHILOSOPHY.md), Section 7. |
| "The Labyrinth" (career discovery stage) | Retired as a stage name | "Choose a Path" | The labyrinth remains the *governing metaphor* for the job market as a whole (see [Theme](THEME.md)), but is not used as a literal UI/stage theme. |
| "Signal vs. Noise" narrative | Retired | Fragmentation → connection narrative | See [README](../../README.md) concept section. |
| Terminal / Matrix cyberpunk visual theme | Retired | TBD — institutional visual identity | To be defined separately from prior aesthetic. |
| "The Anchor" | Renamed | "Getting Started" | Function kept; name simplified. |
| "Lighting the Torch" | Renamed | "Calibrate" | Function kept (anti-Dunning-Kruger rubric step). |
| "The Surveying" | Renamed | "Gap Analysis" | Function kept. |

| "The Oracle's Nod" | Renamed | "Advisor Review" | Persona-dependent name dropped along with The Oracle. |

| "The Treasure" | Renamed | "Payoff & Loop" | "Treasure" read as a game-reward term. |
